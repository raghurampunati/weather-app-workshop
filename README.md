# weather-app-workshop

A small FastAPI weather app built for a hands-on workshop.

Searches a city by name and shows current conditions, using the free
[Open-Meteo](https://open-meteo.com/) API — no API key, no signup.

## Branches

- `master` — stable
- `development` — active work

## Status

Scaffolding only. Application code is not implemented yet.
